# Contribution Guidelines

## Adding to this list

**Edit [list.md](list.md), not README.md.** README.md is generated from list.md
every day and is overwritten.

Please ensure your pull request adheres to the following guidelines:

- Make an individual pull request for each suggestion.
- Use the following format: `* [package](link) - Description.`
- Sort alphabetically inside the categories.
- New categories or improvements to the existing categorization are welcome.
- Check your spelling and grammar.
- The pull request and commit should have a useful title.

## Quality gate

Every reasonable entry is merged into list.md. An entry only shows up in
README.md while it passes the quality gate:

- GitHub repositories need **at least 10 stars**, **a commit within the last
  2 years** and must not be archived.
- All links must work (no 404, no dead domain).

The check runs daily, so an entry appears automatically once it passes (and
disappears if it stops passing). Your pull request shows a preview of the
result, and [excluded.md](excluded.md) lists every hidden entry with the reason.

Thank you for your suggestions!
